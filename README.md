# CareerFlow — landing page

Адаптивный одностраничный сайт-портфолио на HTML5, CSS3 и JavaScript.

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно выполнить в папке проекта:
```bash
python -m http.server 8000
```
Затем откройте `http://localhost:8000`.

## Реализовано
- Адаптивная вёрстка для desktop, tablet и mobile
- Flexbox и CSS Grid
- Именование классов в стиле БЭМ
- Мобильное меню
- Интерактивный список задач в макете dashboard
- FAQ на `details/summary`
- Hover-состояния и поддержка `prefers-reduced-motion`

## Примечание
Это демонстрационный интерфейс для портфолио. Авторизация и регистрация не подключены; кнопки показывают уведомление.
